# For School LP — STUDIO Embed 分割版（8ブロック）

STUDIOのページに「Embed」ブロックを8つ縦に並べ、それぞれにコードを貼ります。

| 順 | ファイル | 中身 | STUDIOで付けるブロックID |
|---|---|---|---|
| 1 | `01-header.txt` | メニューヘッダー | なし（STUDIO側で「固定」にする） |
| 2 | `02-first-view.txt` | ファーストビュー〜メディア掲載（相談画面を含む） | `fv` |
| 3 | `03-why-to-voice.txt` | マグナでできること〜活用シーン | `why` |
| 4 | `04-voice-to-free.txt` | 先生方の声〜安心・安全の取り組み | なし |
| 5 | `05-free-to-easy.txt` | なぜ、マグナはずっと無料なの？ | `free-reason` |
| 6 | `06-easy-to-faq.txt` | 導入はカンタン〜学校劇 | `safe` |
| 7 | `07-faq-to-footer.txt` | よくあるご質問 | `faq` |
| 8 | `08-footer.txt` | フッターメニュー | なし |

## 設定
1. 各ブロックは幅100%。高さは各ファイル冒頭のコメント（ブレイクポイント別）以上に設定。
2. 各ファイルの `PAGE_URL` は公開URL（https://mintflag.com/education）設定済み。
3. ヘッダー（01）のEmbedブロックは、STUDIOの設定で「固定（スクロールしても固定）」にする。
4. 文字・画像・リンクは各ファイル冒頭の `★ ここだけ編集すればOK ★` の `TEXT` / `IMAGES` / `LINKS` を編集。
5. メニューの移動先は `ANCHORS` で変更可（STUDIO側のブロックIDと合わせる）。

## 注意
- ヘッダーのメニューは、STUDIOページ内の別ブロック（ID）へ移動するリンクです（`target="_top"`）。
- ヘッダーの「資料をダウンロード」「気軽に相談する」ボタンは削除済み（ファーストビューにあります）。
- スマホ（〜760px）のヘッダーは元のハンバーガーに戻しました。メニューを開くとリストがバーの下に出ます。
  リストが見えるよう、スマホのヘッダーブロックの高さは 300px にしてください（閉じているときの下側は透明で、後ろのページが見えます。ただしその部分はタップを受けるため、後ろのリンクは押せません）。
- PC・タブレット（761px以上）はメニューを横並び（文字16px）で表示します。
- 「よくあるご質問」を開くとその下が押し下げられ、ブロック末尾の余白が縮みます（高さは指定以上に）。
