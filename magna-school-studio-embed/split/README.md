# For School LP — STUDIO Embed 分割版（7ブロック）

STUDIOのページに「Embed」ブロックを7つ縦に並べ、それぞれにコードを貼ります。

| 順 | ファイル | 中身 | 付けるID（STUDIOのブロックID） |
|---|---|---|---|
| 1 | `01-header.txt` | メニューヘッダー | （なし）※STUDIO側で「固定」にする |
| 2 | `02-first-view.txt` | ファーストビュー〜メディア掲載（相談画面を含む） | `fv` |
| 3 | `03-why-to-voice.txt` | マグナでできること〜活用シーン | `why` |
| 4 | `04-voice-to-free.txt` | 先生方の声〜安心・安全の取り組み | （なし） |
| 5 | `05-free-to-easy.txt` | なぜ、マグナはずっと無料なの？ | `free-reason` |
| 6 | `06-easy-to-faq.txt` | 導入はカンタン〜よくあるご質問 | `safe` |
| 7 | `07-footer.txt` | フッターメニュー | （なし） |

## 設定
1. 各ブロックは幅100%。高さは各ファイル冒頭のコメント（ブレイクポイント別）以上に設定。
2. 各ファイルの設定エリアの `PAGE_URL` に、公開したSTUDIOページのURLを入れてください（ページ内リンク用。特にヘッダー）。
3. ヘッダーのEmbedブロックは、STUDIOの設定で「固定（スクロールしても固定）」にしてください。
4. 文字・画像・リンクは各ファイル冒頭の `★ ここだけ編集すればOK ★` の `TEXT` / `IMAGES` / `LINKS` を編集。
5. 他のブロックへの移動は `ANCHORS` で対応表を変えられます（STUDIO側のブロックIDと合わせてください）。

## 動作の仕組み・注意
- メニューや「ずっと無料」リンクは、STUDIOページ内の別ブロック（ID）へ移動します（親ページを移動させるリンク）。
- 「気軽に相談する」は、ヘッダーでは `fv` ブロック（ファーストビュー）へ移動し、ファーストビュー内のボタンで相談先の選択画面が開きます。
- 「よくある質問」は、6番ブロックの先頭（導入準備）までしか移動できません。FAQの位置まで正確に移動したい場合は、
  6番の代わりに `alt-06a-easy-to-play.txt`（ID: `safe`）と `alt-06b-faq.txt`（ID: `faq`）の2つに分けて貼ってください。
- FAQを開くとその下が押し下げられ、ブロック末尾の余白が縮みます（高さを上記以上にしてください）。
- スマホ幅ではヘッダーの「資料をダウンロード／気軽に相談」ボタンは表示せず、メニューを2行目に並べます（ボタンはファーストビューにあります）。
- スマホ下部の固定バーは、分割版には含まれていません。
