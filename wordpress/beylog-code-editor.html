01 / About

サイトについて

ベイろぐは、ベイブレードXのルールや勝つためのコツを発信し、ブラウザで遊べるシミュレーターを提供しています。

「なぜあのパーツの組み合わせは長く回るのか」「どこから打つとダッシュしやすいのか」といった疑問を、調べて、動かして、シミュレーターとして活用しています。

02 / Rules

ベイブレードXのルール

決まり手とポイント

バトル中の状況に応じてポイントが加算されます。先に規定ポイントに到達したプレイヤーが勝利します。

1pt スピンフィニッシュ 相手のベイよりも長く回り続けた場合。
2pt バーストフィニッシュ 相手のベイのパーツが外れて分離した場合。
2pt オーバーフィニッシュ 相手のベイがスタジアム外周のオーバーゾーン（ポケット）に弾き出された場合。
3pt エクストリームフィニッシュ 相手のベイを中央のエクストリームゾーンに弾き飛ばした場合。

対戦の形式と勝利条件

  • 個人戦（ワンベイ）基本は4ポイント先取。
  • 3on3バトル3つのベイをデッキのように組み合わせて戦う形式で、4ポイント先取。同じパーツを重複して使うことはできません

4つのタイプ

ベイは、アタック、ディフェンス、スタミナ、バランスの4つの考え方で分けられます。アタックは強く当てて飛ばす、ディフェンスは当たりに耐える、スタミナは長く回る、バランスはその中間です。

エクストリームライン

エクストリームラインは、スタジアムの外周にある、ギアがかみ合うラインです。ここに乗ったベイは、勢いをつけて中心へ向かってダッシュします。

実際の大会やルールが変わることがあるので、遊ぶときは必ず最新の公式ルールを確認してください。

03 / Tips

ベイブレードXで勝つためのコツ

01

まずはシュートを練習する

どんなに強いカスタムでも、シュートが安定しないと力を出し切れません。いちばんの基本は、シュートの練習です。

  • まっすぐ素早く引くランチャーの紐は、斜めにならないよう真後ろへ素早く引く。
  • 軸をぶらさないランチャーを持つ手を動かさないと、回転が安定して長く回る。
  • 高さに気をつける高い位置から落とすと、自分でスタジアムの外へ飛び出すミスにつながる。
02

ポイントから戦い方を決める

エクストリームフィニッシュ（3pt）が1回決まれば、あと1ポイントで勝利です。スピンフィニッシュ（1pt）だけで勝つには4回必要です。1ベイの対戦では、スタミナ型で4回勝つより、アタック型でオーバーやエクストリームを2回決めるほうが早く届くこともあります。

  • 早く勝ちたいXダッシュしやすい組み合わせで、エクストリームとオーバーを狙う。
  • じっくり戦いたい長く回る組み合わせで、スピンフィニッシュや相手のバーストを待つ。
  • 迷ったら一度に3ポイント取れる攻め方があるかどうかで選ぶ。
03

タイプの相性を知る

アタックはスタミナに強く、スタミナはディフェンスに強く、ディフェンスはアタックに強い、というじゃんけんのような関係があります。ただし目安なので、パーツの組み合わせや当たり方で結果は変わります。

スタミナ型でアタック型に挑むなら、重めのブレードを選ぶと、一撃で飛ばされたりバーストしたりしにくくなります。

04

ビットで動き方を選ぶ

ビットはスタジアムに接する先端のパーツで、ベイの動き方を大きく左右します。先端の形で3つに分けると覚えやすくなります。

  • 丸い先端（B、FB、Nrなど）摩擦が少なく、長く回る。中央付近で小さく回りやすい。
  • 平らな先端（R、LR、K、Lなど）よく走り回る。Xダッシュや攻撃に向く。
  • 安定型（Hなど）姿勢が崩れにくく、同じ場所で回り続ける。
05

Xダッシュを使いこなす

  • 外周のエクストリームラインにギアがかみ合うと、ベイが一気に加速する。これがXダッシュ。
  • アタック型は、ブレードの外側が重いほど、ダッシュしてぶつかったときの威力が大きくなる。
  • スタミナ型は、相手のダッシュ攻撃をうまくかわして、相手に回転を使わせるのが勝ち筋。
06

3on3は3体で役割を分ける

  • 1ST攻撃型で、先にポイントを取りに行く。
  • 2ND相手のタイプに合わせて、守り型かバランス型を出す。
  • 3RD長期戦に強い持久型で締める。

3on3では同じパーツを使えないので、同じタイプばかり集めるとパーツの取り合いになり、1体ずつが弱くなりがちです。違うタイプを混ぜたほうが、デッキ全体は強くなりやすくなります。

相手が出してきそうなベイを予想して、「防御型が来たらどれをぶつけるか」まで考えておくと、勝率が上がります。

05 / How to use

シミュレーターの使い方

はじめてでも、下記の通りに進めれば動かせます。

  1. 1 モードを選ぶ トップで「シミュレーション」「トーナメント」「プライベートシミュレーション」のどれかを選びます。シミュレーションでは、相手をCPUか2人から選び、CPUの強さ（やさしい／ふつう／つよい）と、1on1か3on3を決めます。
  2. 2 ベイを組む 「次へ（カスタマイズ）」で、ブレード、ラチェット、ビットを1つずつ選びます。左のパネルに、攻撃・防御・持久・ダッシュ・バースト耐性の数字が出ます。3on3では、同じパーツを重ねて選べません。
  3. 3 シュートを選ぶ 「水平」と「斜め」から選びます。水平は、向きを決めず、そのまま回り始めます。斜めは、ドラッグで動き出す向きを決めます。
  4. 4 落とす場所を決める 自分の側（左半分）をタップして、ベイを落とす場所を決めます。相手の落とす位置は、始めるまで分かりません。
  5. 5 スタートする 「スタート」を押すと、カウントのあとにシミュレーションが始まります。決まるごとにポイントが入り、4ポイントを先に取った側が先取です。
  6. 6 プライベートシミュレーション 部屋を作った人が出す4桁の番号を、もう1人が入力すると、2人でつながります。ブラウザどうしが直接つながるので、アカウントは要りません。

  3. STEP 3 公式大会に出る 大会やイベントの日程、ルールは、公式サイトで確認しよう。
